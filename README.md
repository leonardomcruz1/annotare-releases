# Annotare — instaladores

Grave, transcreva e resuma suas reuniões do Teams, Meet e Zoom, com anotações no estilo Notion.

Este repositório guarda **apenas os instaladores** do Annotare para Windows. O código-fonte é privado.

## Instalar

1. Abra a [última versão](https://github.com/leonardomcruz1/annotare-releases/releases/latest) e baixe o arquivo `Annotare-Setup-<versão>.exe`.
2. Execute o instalador. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo** (o instalador ainda não tem assinatura digital).
3. Escolha a pasta e conclua. O Annotare fica no Menu Iniciar e na Área de Trabalho.

## Atualizações

Depois de instalado, o Annotare **se atualiza sozinho**: verifica novas versões ao abrir e a cada 4 horas, baixa em segundo plano e avisa quando estiver pronto. É só clicar em **Reiniciar e atualizar** — suas reuniões, transcrições e anotações são mantidas.
